# SWT
SWT(Solver Want Tuxez!) - является моим репозиторием для установщиком

#УСТАНОВКА
Возьмите любой установщик(к примеру gentoo-etch-installer.sh)
Загрузитесь в ОС(к примеру gentoo/exherbo или любой CLI-линукс)
Далее выполните
curl -LO https://raw.githubusercontent.com/kolonfan4ikxx/SWT/main/gentoo-etch-installer.sh
или если есть wget
wget -LO https://raw.githubusercontent.com/kolonfan4ikxx/SWT/main/gentoo-etch-installer.sh
links2:
links https://github.com/kolonfan4ikxx/SWT
далее выполните
chmod gentoo-etch-installer.sh
и
./gentoo-etch-installer.sh
следите шагам и всё
